# JobTread Partner Atlas

A referral map of the JobTread Marketplace, built by [LuxeCraft Consulting](https://www.luxecraftconsulting.com/) to help marketplace partners point clients to the right next resource.

The atlas is compiled from publicly available information and refreshed periodically, not in real time. There are no paid placements. It is not affiliated with, sponsored by or endorsed by JobTread. Companies should update their information on their own JobTread Marketplace listing and website.
